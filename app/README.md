# Meeting Room Application

React and TypeScript application for the Bandai Meeting Room System.

It contains:

- Administrator dashboard and reports
- Room and workflow management
- Daily, weekly, and monthly scheduling
- Front desk views
- Room tablet display and smart controls
- Lobby room overview with camera previews
- Public daily schedule
- Playwright end-to-end tests

## Run locally

```powershell
npm install
npm run dev
```

## Verify

```powershell
npm run build
npm run test:e2e
```

The older static prototype is retained in `legacy-static` for reference.
